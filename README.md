# java-oop-examples

codeit 스프링 백엔드 부트캠프 17기 "객체지향 프로그래밍의 이해" 강의 예제 코드입니다.
폴더 하나가 Gradle 프로젝트 하나이고, Spring 없이 순수 Java 21로 작성되어 있습니다.

| 폴더 | 교안 | 내용 |
|---|---|---|
| `classlecture` | 2. Java의 클래스와 객체 | 클래스, 객체, 필드, 메서드, 생성자 |
| `inheritance` | 3. 객체지향 프로그래밍의 4가지 핵심 개념 | 상속, 포함, 오버라이딩, super |
| `encapsulation` | 3. 객체지향 프로그래밍의 4가지 핵심 개념 | 캡슐화, 접근 제어자, Getter와 Setter |
| `polymorphism` | 3. 객체지향 프로그래밍의 4가지 핵심 개념 | 다형성, 업캐스팅과 다운캐스팅, instanceof |
| `abstraction` | 3. 객체지향 프로그래밍의 4가지 핵심 개념 | 추상 클래스, final, 인터페이스 |
| `solid` | 4. SOLID 원칙 | SRP, OCP, LSP, ISP, DIP 전후 비교 |

## 실행 방법

1. JDK 21을 준비합니다.
2. IntelliJ에서 보고 싶은 폴더(예: `abstraction`)를 프로젝트로 엽니다.
3. 예제마다 있는 `main` 메서드를 실행합니다.

터미널에서는 폴더 안에서 `./gradlew build`로 컴파일할 수 있습니다.
